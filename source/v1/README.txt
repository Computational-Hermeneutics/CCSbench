CCSbench — a new project

This is a placeholder version. Open Settings ▸ Bench to set this bench's
own name, title, references, repository, language and the Hypothesis group
it shares annotations through. The builder (kit/builder.js) lets you add
real versions, with files you bring in from your own machine.

Annotations are typed: Observation, Question, Metaphor, Pattern, Context,
Critique. Pick one in the annotation box; the annotation is stored with
the tag type:<id> and read back the same.

Repairs are recorded through ◆ Repair on a selection, as Corrected,
Supplied, or Remade (hibi, yobitsugi, kake, after the forms of kintsugi).
Held files are never changed. Flatten derives a child version with the
repairs applied in place, when you want a runnable copy to work with.

The samples that shipped with CCS-WB-classic (FLOW-MATIC 1958 through
Apollo 11 Comanche055 1969) will land in the builder's blank-project
library in Stage 1, when bench-kit's runtime-versions API is released.

Until then, this bench is scaffolding.
